
# Agents

本项目包含编码规范和最佳实践文档集，旨在为开发团队提供统一的代码编写标准。

## 项目简介

这是一个专注于代码规范的知识库，收录了 C# 编程规范和 Git 提交规范，帮助团队保持代码风格一致，提高代码质量。

## 目录结构

```
├── CSharp/
│   ├── CSharp.md           # C# 编码规范 (英文)
│   └── CSharp.zh-CN.md     # C# 编码规范 (中文)
└── Git/
    ├── git-commit/
    │   └── SKILL.md        # Conventional Commits 规范 (英文)
    └── git-commit-zh-cn/
        └── SKILL.md        # Conventional Commits 规范 (中文)
```

## 内容概览

### CSharp 编码规范

涵盖以下主题：

- **优先级** - 规范的优先级别
- **格式** - 代码格式化规则
- **命名** - 命名约定
- **类型与成员** - 类型和成员设计
- **语法与语言特性** - C# 语言特性和语法最佳实践
- **异常处理** - 异常处理规范
- **异步** - 异步编程规范
- **字符串** - 字符串处理
- **注释** - 注释规范
- **编辑既有代码** - 修改现有代码的指导

### Git 提交规范

基于 [Conventional Commits 1.0.0](https://www.conventionalcommits.org/) 规范，包含：

- 提交信息结构
- 提交类型与版本号映射
- 破坏性变更的标记方法
- 多种提交信息示例

## 使用建议

- 新加入团队的开发者应先阅读相关规范文档
- 在编写代码时遵循本规范中的约定
- 提交代码时按照 Conventional Commits 格式编写提交信息
